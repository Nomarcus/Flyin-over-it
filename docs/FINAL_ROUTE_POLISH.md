# Finale route and visual polish

Based on 0783f69ccdd1f5bf1337bc29875c27e191ccf884.

Width increases from 1440 to 1920 world units. Gates use four rhythms: staggered rock shelves, deep stone passages, industrial gantries and broad combat chambers. Clear openings range from 620 to 1350 units, retaining the existing helicopter forces and weapon behavior.

Five required landing sites alternate across the gorge. The player climbs past a shelf, travels sideways and descends onto it; the HUD guides to the next unvisited site. All five must be visited before station completion. Each landing refuels, repairs, rearms and saves progress. The V3 save key preserves older route saves without misplacing their checkpoints.

Visual pass: mineral fissures on rock shelves, two recessed parallax cliff layers, existing detailed character and prop components at shelters and station. Native Canvas visual inspection includes jungle, snow and finale altitude bands. No new raster art is introduced. The finale still returns to the menu without credits.

Regression coverage: real first-four-gate flight simulation, clearance, lateral reach, weather, all five side landings, prevention of skipped shelters, shared cannon/rocket hits, retaliation, saved completion and return to menu. Whole-course manual mobile playthrough remains outstanding.
